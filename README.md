# Customer Review System API

An AI-powered API that processes customer reviews via CSV uploads to automatically analyze individual emotions, generate concise summaries, and predict overall sentiment.

## Features
* 📊 **Bulk Processing:** Upload a single CSV file containing all your customer reviews.
* ❤️ **Emotion Detection:** Extracts specific emotional nuances for every individual customer.
* 📝 **Smart Summarization:** Condenses long, rambling reviews into crisp, readable summaries.
* 📈 **Sentiment Prediction:** Automatically classifies feedback as positive, negative, or neutral.
